# Módulo 1: Copywriting de Vendas

## Método P.A.S.T.O.R.

Estrutura de copy altamente eficaz para infoprodutos e e-commerce.

| Etapa | Significado | Objetivo |
|-------|-------------|----------|
| **P** | Problema | Identifique a dor principal do público |
| **A** | Amplificação | Aprofunde as consequências do problema |
| **S** | Solução | Apresente o produto como saída |
| **T** | Testemunho | Provas sociais reais e verificáveis |
| **O** | Oferta | Detalhes, bônus e preço com ancoragem |
| **R** | Resposta | CTA claro e senso de urgência |

---

## Headline de Venda

Fórmula: **Benefício Imediato + Curiosidade**

```
"O segredo que os grandes players de [Nicho] esconderam de você até hoje
(e como replicar isso)."
```

### Variações de Headline

```
"Como [Persona] conseguiu [Resultado} em [Tempo] sem [Objeção Principal]."

"[Número] erros que estão sabotando suas vendas de [Produto/Nicho] agora."

"O método que [Referência do Nicho] usa para [Resultado Desejado]
— liberado pela primeira vez."
```

---

## Corpo da Cópia — AEO (Answer Engine Optimization)

Use perguntas reais do público como subtítulos. Isso otimiza para buscas em IAs (ChatGPT, Gemini, Perplexity).

### Exemplos de subtítulos AEO

- "Como ganhar dinheiro com [Nicho] em 2026?"
- "Qual o melhor caminho para [Resultado]?"
- "Quanto tempo leva para [Transformação]?"
- "O que diferencia quem [Consegue} de quem [Não Consegue}?"

---

## Gatilho 2026: Prova Social Assistida por IA

Combine **resultados reais** com **dados estruturados** para ser citado por mecanismos de IA.

### Para Landing Pages

```html
<!-- Schema Markup de Review/Produto -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Nome do Produto",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.9",
    "reviewCount": "312"
  }
}
</script>
```

### Boas práticas de prova social

- Mencione nome + transformação específica (não apenas "Fulano melhorou")
- Use dados mensuráveis: "aumentou em 47% em 30 dias"
- Inclua prints ou depoimentos em vídeo como embed
- Atualize depoimentos a cada 90 dias para sinalizar relevância ao algoritmo

## Templates de Copy Prontos

### Template de E-mail de Lançamento

```
Assunto: Você já tentou [Solução Comum] e não funcionou?

[NOME],

Se você já tentou [Solução A], [Solução B] ou [Solução C] e ainda está
preso em [Situação Problema], não é culpa sua.

O problema é que ninguém te contou sobre [Elemento Diferenciador].

[Parágrafo de amplificação da dor]

Foi exatamente por isso que criei o [Nome do Produto]:
[Promessa principal em uma frase].

[Prova social: 1 depoimento curto e específico]

Hoje, por [Preço com ancoragem — de R$X por apenas R$Y]:

→ [Benefício 1]
→ [Benefício 2]
→ [Benefício 3]
→ Bônus: [Bônus de alto valor percebido]

Mas atenção: [Urgência/Escassez real e verificável].

[CTA claro com link]

[Assinatura]
```

### Template de Post de Vendas (Feed/Stories)

```
[Hook visual: imagem que gera dissonância ou curiosidade]

"[Afirmação contraintuitiva ou resultado surpreendente]"

Eu aprendi isso depois de [Contexto pessoal que gera identificação].

Aqui está o que ninguém fala sobre [Tema]:
↓
[Bullet 1 de valor]
[Bullet 2 de valor]
[Bullet 3 de valor]

Se você quer [Transformação], eu criei exatamente isso em [Produto].

Comenta [PALAVRA-CHAVE] aqui embaixo e eu te envio os detalhes no privado.
```
