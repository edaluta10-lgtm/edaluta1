# Módulo 4: Checklist de SEO 2026 para o Edaluta

## Visão Geral das Técnicas

| Elemento | Técnica Recomendada |
|----------|---------------------|
| SEO de Voz | Use frases naturais na descrição como "Como eu faço para..." |
| Micro-Momentos | Títulos que respondem "O que é", "Como fazer" ou "Onde comprar" |
| GEO | Otimize o texto para ser citado por modelos de IA (ChatGPT, Gemini, Perplexity) |
| Retenção | Insira um "Open Loop" (promessa de algo incrível no final) nos primeiros 30s |

---

## 1. SEO de Voz

Assistentes de voz (Google Assistant, Siri, Alexa) respondem perguntas conversacionais. Otimize para aparecer nessas respostas.

### Como aplicar

- Use linguagem conversacional nas descrições e transcrições
- Inclua frases como:
  - "Como eu faço para..."
  - "Qual é a melhor forma de..."
  - "O que acontece quando..."
- Responda a pergunta de forma direta nos primeiros 2 parágrafos
- Tamanho ideal da resposta para snippets de voz: **40–60 palavras**

---

## 2. Micro-Momentos

Google classifica buscas em 4 micro-momentos. Apareça em cada um deles:

| Micro-Momento | Intenção | Formato de Título |
|---------------|----------|------------------|
| **"Eu quero saber"** | Informação | "O que é [Tema]" / "Como funciona [Produto]" |
| **"Eu quero fazer"** | Tutorial | "Como fazer [Ação] passo a passo" |
| **"Eu quero ir"** | Local/Evento | "Onde encontrar [Produto/Serviço]" |
| **"Eu quero comprar"** | Conversão | "Melhor [Produto] de 2026 / Vale a pena?" |

---

## 3. GEO — Generative Engine Optimization

Em 2026, mecanismos como **ChatGPT Search**, **Gemini** e **Perplexity** citam fontes em suas respostas. Ser citado por uma IA = tráfego orgânico de alta qualidade.

### Princípios do GEO

**a) Clareza factual**
- Afirmações devem ser verificáveis e específicas
- Prefira "aumentou 47% em 30 dias" a "cresceu muito"

**b) Estrutura de fácil extração**
- Use listas, tabelas e subtítulos claros
- Responda a pergunta no início do parágrafo, não no final

**c) Autoridade de domínio**
- Crie conteúdo longo e aprofundado (mínimo 1.500 palavras para artigos)
- Atualize o conteúdo periodicamente — IAs preferem fontes recentes

**d) Dados estruturados (Schema Markup)**
```html
<!-- Para vídeos — aumenta chances de citação por IAs -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "Título do Vídeo",
  "description": "Descrição com palavra-chave",
  "uploadDate": "2026-03-01",
  "thumbnailUrl": "https://...",
  "author": {
    "@type": "Person",
    "name": "Edaluta"
  }
}
</script>
```

**e) Citabilidade**
- Crie frases "citáveis" — afirmações claras, únicas e memoráveis
- Exemplo: *"Em 2026, conteúdo sem estrutura AEO é invisível para IA."*

## 4. Retenção — Open Loop

O algoritmo do YouTube e Instagram mede **retenção** como principal métrica de qualidade.

### Técnica do Open Loop

Crie uma promessa no início que só será entregue no final.

```
Estrutura:
[0–30s] "Fica até o final porque vou revelar [Elemento X] que
         [Benefício significativo]."

[Meio do vídeo] "Antes de chegar no [Elemento X], preciso que
                  você entenda [Contexto necessário]..."

[Final] Entrega do [Elemento X] + CTA
```

### Outros gatilhos de retenção

| Técnica | Quando usar |
|---------|-------------|
| **Teaser do próximo ponto** | A cada 2–3 minutos: "E o próximo ponto vai te surpreender..." |
| **Pergunta retórica** | Mantém o espectador mentalmente ativo |
| **Referência futura** | "Vou mostrar um exemplo real disto em alguns instantes" |
| **Statcut** | Dado numérico surpresa para quebrar o ritmo e prender atenção |

## 5. Calendário de Revisão de Conteúdo

Para manter relevância nos algoritmos de IA e busca:

| Frequência | Ação |
|------------|------|
| Mensal | Atualize dados e estatísticas nos top 5 vídeos |
| Trimestral | Revise títulos e thumbnails dos vídeos com CTR abaixo de 4% |
| Semestral | Reescreva descrições dos vídeos mais visualizados com novas palavras-chave |
| Anual | Recrie (ou delete) conteúdos com queda persistente de impressões |
