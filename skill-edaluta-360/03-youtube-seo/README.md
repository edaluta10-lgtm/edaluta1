# Módulo 3: YouTube SEO & Thumbnails

## Thumbnails — A "Isca"

### Regra dos 3 Elementos

Uma thumbnail eficaz tem **no máximo 3 elementos visuais**:

1. **Rosto expressivo** — emoção clara (surpresa, determinação, espanto)
2. **Objeto de desejo ou medo** — o que o vídeo entrega ou evita
3. **Texto de até 3 palavras** — complementa, não repete o título

> Mais de 3 elementos = poluição visual = menos cliques

### Contraste Cromático

Use **cores complementares** para se destacar no feed do YouTube.

| Combinação | Impacto |
|------------|---------|
| Azul + Laranja | Alta energia, tecnologia, negócios |
| Verde + Vermelho | Urgência, saúde, comparação |
| Roxo + Amarelo | Criatividade, luxo, educação |
| Preto + Branco + 1 cor forte | Premium, minimalismo impactante |

**Dica:** Visualize a thumbnail em 120x68px (tamanho mobile no feed). Se os elementos não forem legíveis, redesenhe.

### Elementos de Alto CTR

| Elemento | Por que funciona |
|----------|-----------------|
| Visual "Antes e Depois" | Mostra progresso → desperta curiosidade técnica |
| Gráfico de crescimento | Credibilidade + promessa visual de resultado |
| Rosto com expressão exagerada | Contagia emocionalmente o espectador |
| Seta ou dedo apontando | Direciona o olhar para o texto ou elemento-chave |
| Fundo desfocado/escuro | Destaca o sujeito principal |

## Título e Headline

### Estrutura recomendada

```
[Palavra-Chave Forte] + [Promessa ou Curiosidade] + [Número ou Ano]
```

**Exemplos:**

```
"Marketing Digital 2026: O guia definitivo para vender sem anúncios."

"Copywriting: 7 técnicas que triplicaram minhas vendas em 30 dias."

"YouTube SEO 2026: Como aparecer no topo sem gastar nada."
```

### Regras de título

- **Limite:** 60 caracteres para não ser cortado em mobile
- Palavra-chave principal **nos primeiros 30 caracteres**
- Evite clickbait sem entrega — o algoritmo analisa retenção como punição
- Use números ímpares (7, 11, 3) — performam melhor que pares em CTR
- Evite maiúsculas em excesso — lido como spam pelo algoritmo desde 2024

## Descrição Otimizada

### Estrutura das primeiras 2 linhas (críticas)

As primeiras 150 caracteres aparecem **antes do "ver mais"** — são as mais indexadas.

```
[Palavra-chave principal] + [Promessa] + variação de cauda longa.
Exemplo: "Aprenda Marketing Digital 2026: estratégias para vender sem anúncios
e crescer organicamente no YouTube e Instagram."
```

### Estrutura completa da descrição

```
[Linhas 1–2: Palavra-chave + Promessa]

📌 Neste vídeo você vai aprender:
→ [Ponto 1 — use variação da palavra-chave]
→ [Ponto 2]
→ [Ponto 3]

⏱ Capítulos:
00:00 Introdução
02:15 [Tema 1]
08:40 [Tema 2]
15:20 [Tema 3]
22:00 Conclusão

🔗 Links mencionados:
[Produto/Recurso 1]: [URL]
[Produto/Recurso 2]: [URL]

📲 Me siga:
Instagram: @edaluta
[Outras redes]

---
[Palavras-chave de cauda longa em parágrafo natural — não lista de tags]
Exemplo: "Se você quer saber como fazer marketing digital do zero, como vender
online em 2026 ou como criar conteúdo que converte, este canal é para você."
```

## Capítulos (Timestamps)

O Google/YouTube usa capítulos para **indexar partes específicas** em buscas de IA.

### Boas práticas

- Adicione sempre que o vídeo tiver mais de 5 minutos
- Nomeie os capítulos com **variações da palavra-chave** principal
- Primeiro capítulo sempre em `00:00`
- Mínimo de 3 capítulos para ativar o recurso

## Tags — Técnica da Pirâmide

```
Nível 1 (base — Tag Única):
  "Edaluta" / Nome do canal

Nível 2 (Tags Específicas — assunto do vídeo):
  "copywriting para infoprodutos"
  "como escrever copy de vendas"
  "P.A.S.T.O.R. copy"

Nível 3 (Tags Amplas — nicho principal):
  "marketing digital"
  "vendas online"
  "empreendedorismo digital"
```

**Total recomendado:** 8–15 tags. Mais de 20 sinaliza spam.

---

## Hashtags

Use apenas **3 a 5 hashtags** na descrição ou no final do título.

Em 2026, o excesso de hashtags é penalizado pelo algoritmo como conteúdo spam.

```
Exemplos para o Edaluta:
#MarketingDigital #Copywriting #Edaluta
```

Nunca use hashtags genéricas (#viral, #fyp, #trending) — têm baixo poder de segmentação.

## Checklist de Publicação no YouTube

- [ ] Thumbnail com 3 elementos, contraste cromático e legível em mobile
- [ ] Título dentro de 60 caracteres com palavra-chave nos primeiros 30
- [ ] Primeiras 2 linhas da descrição com palavra-chave + promessa
- [ ] Capítulos/timestamps configurados
- [ ] Tags seguindo a pirâmide (8–15 tags)
- [ ] Máximo de 3–5 hashtags
- [ ] Card e tela final configurados (CTA para próximo vídeo ou inscrição)
- [ ] Playlist associada ao vídeo
- [ ] Miniatura personalizada (não automática)
