# Template de SEO 2026 — Checklist de Publicação

> Preencha todos os campos entre `[colchetes]` e marque cada item ao publicar.

---

## DADOS DO CONTEÚDO

```
Título do vídeo/post: [TÍTULO FINAL]
Palavra-chave principal: [ex: Copywriting 2026]
Variações de cauda longa:
  - [ex: como escrever copy de vendas]
  - [ex: método pastor copywriting]
  - [ex: copywriting para infoprodutos]
Plataforma: [YouTube / Instagram / Blog / Todos]
Data de publicação: [DD/MM/AAAA]
```

---

## 1. SEO DE VOZ

> Otimize para assistentes de voz (Google Assistant, Siri, Alexa).

**Checklist:**
- [ ] Descrição contém pelo menos 1 frase conversacional natural
- [ ] A pergunta principal que o vídeo responde está escrita como o público falaria

**Preencha — pergunta conversacional do seu conteúdo:**
```
Pergunta que o público faria por voz:
"[ex: Como eu faço para aprender copywriting do zero?]"

Resposta direta (máximo 60 palavras — ideal para snippet de voz):
"[Escreva aqui a resposta direta em linguagem natural]"
```

**Onde inserir:**
- Primeiros 2 parágrafos da descrição do YouTube
- Primeiro parágrafo de um artigo de blog
- Legenda do post no Instagram (primeiras 2 linhas)

---

## 2. MICRO-MOMENTOS

> Adapte o título para capturar o momento certo de busca.

**Identifique o micro-momento do seu conteúdo:**

| Micro-Momento | Meu conteúdo se encaixa aqui? | Formato de Título |
|---------------|-------------------------------|------------------|
| "Eu quero saber" | [ ] Sim  [ ] Não | "O que é [TEMA]" |
| "Eu quero fazer" | [ ] Sim  [ ] Não | "Como fazer [AÇÃO] passo a passo" |
| "Eu quero ir" | [ ] Sim  [ ] Não | "Onde encontrar [PRODUTO/SERVIÇO]" |
| "Eu quero comprar" | [ ] Sim  [ ] Não | "Melhor [PRODUTO] 2026 / Vale a pena?" |

**Preencha o título adaptado para o micro-momento escolhido:**
```
Título para micro-momento:
"[ex: Como fazer copywriting do zero — passo a passo 2026]"
```

---

## 3. GEO — Generative Engine Optimization

> Otimize para ser citado por IAs (ChatGPT, Gemini, Perplexity).

### Checklist GEO

**Clareza factual:**
- [ ] Todas as afirmações do conteúdo são específicas e verificáveis
- [ ] Dados com números concretos (ex: "47% de aumento" em vez de "cresceu muito")

**Estrutura de fácil extração:**
- [ ] Conteúdo usa listas, tabelas e subtítulos claros
- [ ] Cada seção responde uma pergunta no início (não no final)

**Autoridade:**
- [ ] Conteúdo tem mínimo de [1.500 palavras para artigo / 60s para vídeo]
- [ ] Data de publicação/atualização visível

**Frase citável do conteúdo:**
```
Escreva 1 frase única, clara e memorável sobre o tema:
"[ex: Em 2026, conteúdo sem estrutura AEO é invisível para mecanismos de IA.]"
```

**Schema Markup (somente para Landing Pages e Blogs):**
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "[TÍTULO DO VÍDEO]",
  "description": "[DESCRIÇÃO COM PALAVRA-CHAVE]",
  "uploadDate": "[AAAA-MM-DD]",
  "thumbnailUrl": "[URL DA THUMBNAIL]",
  "author": {
    "@type": "Person",
    "name": "Edaluta"
  }
}
</script>
```

## 4. RETENÇÃO — Open Loop

> Crie uma promessa nos primeiros 30 segundos que só será entregue no final.

**Preencha o Open Loop do seu vídeo:**

```
[0–30s] Frase do Open Loop:
"Fica até o final porque vou revelar [ELEMENTO X]
que vai [BENEFÍCIO SIGNIFICATIVO PARA A PERSONA]."

Elemento X: [ex: o método exato que uso para escrever copy em 20 minutos]
Benefício: [ex: te economizar horas e dobrar sua taxa de conversão]

[Meio do vídeo] Teaser de retenção:
"Antes de chegar no [ELEMENTO X], preciso que você entenda [CONTEXTO NECESSÁRIO]..."

Contexto necessário: [ex: por que a maioria das copies falha logo na headline]

[Final do vídeo] Entrega + CTA:
"Agora sim — o [ELEMENTO X] que prometei no início:
[REVELAÇÃO CONCRETA].
Se você quiser [PRÓXIMO PASSO], comenta [PALAVRA-CHAVE] aqui."

Revelação concreta: [escreva o que de fato será entregue]
```

```

Revisão Mensal (dados e estatísticas):
Próxima revisão: [DD/MM/AAAA]
O que revisar: dados numéricos, exemplos e cases citados

Revisão Trimestral (título e thumbnail):
Próxima revisão: [DD/MM/AAAA]

Revisão Semestral (descrição e palavras-chave):

Revisão Anual (relevância geral):
Próxima revisão: [DD/MM/AAAA]
Decisão: [ ] Atualizar  [ ] Recriar  [ ] Deletar
```
