## THUMBNAIL — Briefing para Designer

```
Elemento 1 — Rosto:
Expressão: [ESCOLHA: surpresa / determinação / espanto / empolgação]
Posição: [ESCOLHA: esquerda / direita / centro]

Elemento 2 — Objeto de desejo ou medo:
Objeto: [ex: gráfico de crescimento, dinheiro, ícone de erro, produto]
Posição: [oposto ao rosto]

Elemento 3 — Texto (máximo 3 palavras):
Texto: "[PALAVRA 1] [PALAVRA 2] [PALAVRA 3]"
Cor do texto: [ex: amarelo #FFD700 com contorno preto]

Paleta de cores:
Fundo: [ex: azul escuro #0A1628]
Destaque: [ex: laranja #FF6B00]
Combinação recomendada: [ESCOLHA: Azul+Laranja / Verde+Vermelho / Roxo+Amarelo]

Tamanho final: 1280x720px
Teste obrigatório: visualize em 120x68px para verificar legibilidade mobile
```

| Urgência | "Muda em 2026" |
| Resultado | "R$[X] em [Y] dias" |
| Erro comum | "Você errou aqui" |
| Comparação | "Antes vs Depois" |

## TÍTULO DO VÍDEO

**Estrutura:**
```
[PALAVRA-CHAVE PRINCIPAL] + [PROMESSA OU CURIOSIDADE] + [NÚMERO OU ANO]
```

**Preencha:**
```
Título: "[PALAVRA-CHAVE]: [PROMESSA/CURIOSIDADE] [NÚMERO/ANO]"

ex: "Copywriting 2026: 7 técnicas que triplicam vendas sem anúncios."
```

- Palavra-chave principal: `[ex: Marketing Digital, Copywriting, YouTube SEO]`
- Promessa ou curiosidade: `[ex: o guia definitivo / o erro que todos cometem]`
- Número ou ano: `[ex: 2026 / 7 passos / 3 erros]`

**Checklist do título:**
- [ ] Máximo de 60 caracteres
- [ ] Palavra-chave nos primeiros 30 caracteres
- [ ] Sem maiúsculas excessivas
- [ ] Número no título (preferencialmente ímpar: 3, 5, 7, 11)

## DESCRIÇÃO DO VÍDEO

### Linhas 1–2 (críticas — aparecem antes do "ver mais")

```
[PALAVRA-CHAVE PRINCIPAL]: [PROMESSA] — [VARIAÇÃO DE CAUDA LONGA].

ex: "Copywriting 2026: aprenda a escrever textos que vendem sem anúncios
e aumente sua conversão com o método P.A.S.T.O.R."
```

**Preencha:**
- Palavra-chave: `[ex: Copywriting 2026]`
- Promessa: `[ex: aprenda a escrever textos que vendem]`
- Variação de cauda longa: `[ex: sem precisar de anúncios pagos]`

## TAGS — Pirâmide

```
Nível 1 — Tag Única (identidade do canal):
"Edaluta"

Nível 2 — Tags Específicas (3–5 tags sobre o assunto do vídeo):
"[TEMA ESPECÍFICO DO VÍDEO]"
"[VARIAÇÃO DO TEMA]"
"[SUBTEMA OU TÉCNICA MENCIONADA]"
"[PROBLEMA QUE O VÍDEO RESOLVE]"

Nível 3 — Tags Amplas (3–5 tags do nicho principal):
"[NICHO PRINCIPAL]"
"[CATEGORIA AMPLA]"
"[ÁREA DE CONHECIMENTO]"
```

**Exemplo preenchido:**
```
Nível 1: "Edaluta"
Nível 2: "copywriting para iniciantes", "método pastor copy", "como escrever copy de vendas"
Nível 3: "marketing digital", "vendas online", "empreendedorismo digital"
```

**Total de tags:** entre 8 e 15. Nunca mais de 20.

## CHECKLIST DE PUBLICAÇÃO

### Antes de publicar
- [ ] Thumbnail com 3 elementos, contraste e legível em 120x68px
- [ ] Título dentro de 60 caracteres, palavra-chave nos primeiros 30
- [ ] Primeiras 2 linhas da descrição com palavra-chave + promessa
- [ ] Pontos do vídeo listados na descrição
- [ ] Timestamps/capítulos preenchidos (mínimo 3)
- [ ] Tags em pirâmide (8–15 tags)
- [ ] Máximo de 5 hashtags
- [ ] Miniatura personalizada selecionada (não automática)
- [ ] Playlist associada ao vídeo

### Após publicar (primeiras 48h)
- [ ] Compartilhado em Stories/Reels como preview
- [ ] Postado na Comunidade do YouTube
- [ ] Primeiros 20 comentários respondidos
- [ ] CTR verificado após 24h (meta: >4%)
- [ ] Retenção média verificada (meta: >40%)
