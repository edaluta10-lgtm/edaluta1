# Módulo 2: Cortes Virais (Podcast & Shorts)

## A Regra dos 1.5 Segundos

Em 2026, a retenção depende dos **primeiros 1.5 segundos**. O algoritmo analisa o abandono quadro a quadro. Se o usuário sair antes de 3 segundos, o corte perde distribuição imediata.

---

## O Gancho (Hook)

### Estrutura recomendada

```
[Conclusão Chocante ou Frase Polêmica]
  ↓
[Contexto que justifica a afirmação]
  ↓
[Desenvolvimento + Virada]
```

**Errado:**
> "Hoje vamos falar sobre como o mercado digital mudou..."

**Certo:**
> "95% das pessoas que tentam vender online estão cometendo esse erro agora."
> *(contexto depois)*

### Tipos de Hook que performam em 2026

| Tipo | Exemplo |
|------|---------|
| Polêmico | "Parar de postar todo dia foi o que salvou meu canal." |
| Contraintuitivo | "Menos seguidores = mais vendas. Vou te provar." |
| Urgência | "Isso vai mudar completamente em 60 dias. Veja agora." |
| Pergunta direta | "Você sabe por que seu conteúdo não vende?" |
| Revelação | "Finalmente posso falar sobre o que realmente aconteceu." |

## Edição Psicológica

### Legendas Dinâmicas

- **Obrigatórias** — 85% dos vídeos são assistidos sem som (mobile)
- Use cores para destacar palavras de ação:
  - `#FF4500` (Laranja-vermelho) → Dinheiro, Erro, Atenção
  - `#FFD700` (Amarelo) → Revelado, Segredo, Novo
  - `#00FF88` (Verde) → Resultado, Crescimento, Aprovado
- Fonte sugerida: **Montserrat Bold** ou **Anton** — leitura rápida em tela pequena
- Tamanho mínimo: 48px para mobile

### Loop Infinito

O final do corte deve criar uma "faísca de curiosidade" que leve o usuário a reassistir ou clicar.

```
Técnica: Termine com uma pergunta que o início responde.

Exemplo:
- Final: "E foi exatamente isso que mudou tudo. Mas por quê funcionou?"
- Início: "Porque 99% das pessoas ignoram esse detalhe..."
```

### Ritmo de Corte

| Segmento | Duração recomendada |
|----------|-------------------|
| Hook | 0–3s |
| Desenvolvimento | 3–45s |
| Virada/Revelação | 45–55s |
| CTA | 55–60s |

Para Shorts/Reels de até 60s, mantenha cortes a cada **2–4 segundos** no hook e a cada **5–8 segundos** no desenvolvimento.

## CTA On-Platform (Estratégia de Comentário)

### Por que não pedir "link na bio" logo de cara?

Pedir o link na bio imediatamente reduz o engajamento. O algoritmo interpreta isso como sinal de "conteúdo publicitário" e reduz a distribuição orgânica.

### Método da Palavra-Chave

```
"Se você quer [Benefício], comenta aqui embaixo: [PALAVRA-CHAVE]
que eu te envio no privado."
```

**Exemplos de palavras-chave por nicho:**

| Nicho | Palavra-Chave |
|-------|--------------|
| Marketing Digital | MÉTODO |
| Finanças | INVESTIR |
| Saúde/Fitness | TREINO |
| Negócios | CRESCER |
| Educação | APRENDER |

### Por que funciona?

1. **Comentários** são o sinal de engajamento mais forte para o algoritmo em 2026
2. O bot envia o link via DM automaticamente (ManyChat, Manychat para Instagram/YouTube)
3. Aumento médio de engajamento: **10x** comparado ao "link na bio"
4. Cria uma lista de leads quente com intenção explícita

### Configuração de Bot Recomendada

```
Trigger: comentário contendo [PALAVRA-CHAVE]

Mensagem automática no DM:
"Oi [Nome]! Vi que você comentou [PALAVRA-CHAVE] —
aqui está o link que prometei: [URL]

Qualquer dúvida, é só me chamar!"
```

## Checklist de Corte Viral

- [ ] Hook começa com conclusão ou afirmação chocante
- [ ] Primeiros 1.5s sem logo, sem intro, sem música de abertura
- [ ] Legendas dinâmicas com cores por tipo de palavra
- [ ] Cortes rítmicos a cada 2–4s no hook
- [ ] Loop infinito configurado no final
- [ ] CTA de palavra-chave (sem pedir "link na bio" de imediato)
- [ ] Áudio limpo — sem ruído de fundo perceptível
- [ ] Proporção 9:16 para Shorts/Reels, 16:9 para YouTube tradicional
